# Task Sage – Your AI Consultant 🧙‍♂️

Task Sage – Your AI Consultant is a powerful, AI-driven task analyzer designed and developed solely by **Aman Srivastava**.  
This application allows users to input tasks, which are then evaluated by an LLM (Groq API) to determine:

- 📌 **Priority Level**: High, Medium, Low
- 🗓️ **Suggested Deadline**: Recommended time to complete the task
- 🎯 **Focus Score**: A value between 1-100 based on urgency and importance
- 💡 **Motivational Tip**: A witty one-liner tip to keep you productive!

The output is presented through an intuitive **Streamlit web application**.

---

## 🚀 Features

✅ Real-time task evaluation using Groq's LLM  
✅ User-driven task input (no pre-defined files)  
✅ Automatic priority, deadline, and focus score suggestion  
✅ Fun productivity tips for each task  
✅ Easy-to-use Streamlit interface

## ⚙️ Setup Instructions (For Authorized Users Only)

> **Note**: This software is proprietary and for personal or authorized use only.

1. **Clone this repository** (only if you have explicit permission):
git clone <private-repo-url>
cd TaskSage_AI

2. **Create and activate a virtual environment**:
python -m venv venv
venv\Scripts\activate # For Windows
source venv/bin/activate # For macOS/Linux

3. **Install required dependencies**:
pip install -r requirements.txt

4. **Configure Groq API Key**:
Create a `.env` file in the project root with:
GROQ_API_KEY=your_actual_groq_api_key_here

5. **Run the Streamlit application**:
streamlit run streamlit_app.py
